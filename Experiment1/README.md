## 概述

本实验涵盖四种基本图像处理操作，使用MATLAB和C++/OpenCV实现。这些操作构成了许多计算机视觉算法的基础。

---

## 程序列表

### 1. 距离变换 (`DistanceTransform/`)

**语言:** MATLAB

**描述:**
距离变换计算每个像素到二值图像中最近前景（非零）像素的距离。本实现使用**Chamfer距离变换**算法，对图像进行两次扫描：

- **第一次扫描（从上到下，从左到右）：** 检查上方和左方的邻居
- **第二次扫描（从下到上，从右到左）：** 检查下方和右方的邻居，更新最小值

**文件:**
- `main.m` — 主脚本，读取图像，转为二值图，调用MyDisTrans
- `MyDisTrans.m` — 核心算法实现

---

### 2. 直方图显示 (`HistogramDisplay.cpp`)

**语言:** C++ / OpenCV

**描述:**
手动计算并可视化图像的灰度直方图。程序未使用OpenCV内置的`calcHist`和`normalize`函数，而是：

1. 遍历所有像素，统计每个灰度级（0-255）的出现次数
2. 将直方图归一化以适应显示画布
3. 使用`rectangle()`绘制柱状图

**文件:**
- `HistogramDisplay.cpp` — 完整实现

---

### 3. 卷积 (`Convolution.cpp`)

**语言:** C++ / OpenCV

**描述:**
使用两种不同方法实现高斯卷积：

1. **直接空间卷积** — 使用四层嵌套循环应用128×128高斯核，边界跳过（BORDER_CONSTANT）
2. **基于FFT的卷积** — 将图像和核填充到最优DFT大小，执行DFT，在频域相乘，然后逆DFT得到结果

高斯核使用σ=20.0生成，并归一化使所有权值之和为1。

**文件:**
- `Convolution.cpp` — 两种实现（空间域和基于FFT）

---

### 4. 积分图像 (`IntegralImage/`)

**语言:** MATLAB

**描述:**
计算灰度图像的**积分图**（求和面积表）。位置(i,j)处的积分图像包含该位置上方和左侧所有像素值的总和：

```
SA(i,j) = img(i,j) + SA(i-1,j) + SA(i,j-1) - SA(i-1,j-1)
```

该递归公式在O(M×N)预处理后，可以实现任意矩形区域和的O(1)计算。

**文件:**
- `main.m` — 主脚本
- `MyInteImg.m` — 核心算法实现

## 注意事项

- 输入图像可随意更换
- 在MATLAB中，运算得到的矩阵数据不能直接输出为图像——可能需要进行类型转换（如`uint8()`）
