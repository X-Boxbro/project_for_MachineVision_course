## 程序列表

### 1. OTSU阈值 (`OTSUThreshold/`)

**语言:** MATLAB

**描述:**
实现**OTSU法**（大津法，1979年）进行自动阈值选择。算法步骤：

1. **计算直方图** — 统计每个灰度级的像素个数
2. **计算概率分布** — 将直方图像素数除以总像素数
3. **遍历所有阈值（0-255）：**
   - 将像素分为两类（背景/前景）
   - 计算类权重（w1, w2）和类均值（u1, u2）
   - 计算**类间方差**：`σ_B² = w1 × w2 × (u1 - u2)²`
4. **选择最优阈值** — 使σ_B²最大的阈值

**OTSU原理：** 最大类间方差意味着两个类别（前景/背景）最易分离。

**文件:**
- `main.m` — 主脚本
- `MyOTSU.m` — OTSU核心算法实现

### 2. 迭代最优阈值 (`IterativeOptimalThreshold/`)

**语言:** MATLAB

**描述:**
实现**迭代阈值选择**——另一种自动阈值方法。算法步骤：

1. **初始化阈值** — T = (min + max) / 2（图像灰度范围的中点）
2. **迭代直到收敛：**
   - 将像素分为G1（≥ T）和G2（< T）
   - 计算两组的均值：u1 = mean(G1), u2 = mean(G2)
   - 更新阈值：T_new = (u1 + u2) / 2
   - 如果 |T_new - T| < ε（0.5），停止
3. **应用最终阈值** 进行二值化分割

**收敛保证：** 由于均值u1和u2趋于稳定，阈值总会收敛。

**文件:**
- `main.m` — 主脚本，包含收敛过程图
- `MyOptimalThreshold.m` — 迭代核心算法

### 3. P率阈值化 (`PThreshold.cpp`)

**语言:** C++ / OpenCV

**描述:**
实现**P率阈值化**——一种自适应阈值方法，选择阈值T使得恰好p%的像素比T更暗（或更亮）。

1. **计算直方图**
2. **从灰度级0开始向上累加**
3. **找到阈值T** — 累计像素数 ≥ p × 总像素数
4. **二值化** — 像素 ≥ T → 白色（前景），像素 < T → 黑色（背景）

默认p = 0.5（中位数分割），可调整为其他值。

**文件:**
- `PThreshold.cpp` — P率阈值化完整实现

### 4. 内边界跟踪 (`InnerContour.cpp`)

**语言:** C++ / OpenCV

**描述:**
使用**形态学腐蚀**（形态学差分）检测物体轮廓。算法步骤：

1. **腐蚀** — 对每个像素，检查其3×3邻域（共9个像素）是否全为前景（255）。如果是，保持为前景；否则，设为背景。
2. **轮廓提取** — `轮廓图 = 原图 - 腐蚀后的图`

**核心原理：** 前景内部像素在腐蚀后保留（有8个前景邻居），但边界像素变为背景（缺少至少一个前景邻居）。差值同时显示外边界和内边界。

**文件:**
- `InnerContour.cpp` — 轮廓检测完整实现
