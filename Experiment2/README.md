## 概述

本实验涵盖空间域滤波和边缘检测技术，包括线性与非线性滤波器，以及经典的差分边缘检测器（Sobel算子）。

## 程序列表

### 1. 中值滤波 (`MedianFilter/`)

**语言:** MATLAB

**描述:**
实现**3×3中值滤波**用于去噪。与线性滤波器（均值/盒滤波器）不同，中值滤波器是**非线性**操作：

1. 提取每个像素周围的3×3邻域（共9个像素）
2. 将9个像素值按升序排列
3. 取中位数（第5个元素）作为输出

中值滤波器特别擅长去除**椒盐噪声**，同时比均值滤波更好地保持边缘。使用**复制(replicate)边界填充**。

**文件:**
- `main.m` — 主脚本，包含环境设置、图像加载和结果显示
- `MyMedfilt2.m` — 中值滤波核心实现

### 2. 边缘检测 (`EdgeDetection.cpp`)

**语言:** C++ / OpenCV

**描述:**
实现**Sobel算子**进行边缘检测。Sobel算子使用两个3×3卷积核：

- **Gx核（水平梯度）：** 检测垂直边缘（从左到右的灰度变化）
- **Gy核（垂直梯度）：** 检测水平边缘（从上到下的灰度变化）

最终边缘强度计算为：`G = sqrt(Gx² + Gy²)`

边界处理使用**replicate**模式（边缘像素被夹取到边界值）。

**文件:**
- `EdgeDetection.cpp` — Sobel边缘检测完整实现

---

### 3. 直方图均衡化 (`HistogramEqualization.cpp`)

**语言:** C++ / OpenCV

**描述:**
实现**直方图均衡化**用于自动对比度增强。算法步骤：

1. **计算直方图** — 统计每个灰度级（0-255）的像素个数
2. **计算累计直方图（CDF）** — 直方图的累加和
3. **构建查找表（LUT）** — `map[k] = round(255 * CDF[k] / totalPixels)`
4. **应用映射** — 使用LUT替换每个像素值

结果：输出图像的直方图分布更加均匀，增强了整体对比度。

**文件:**
- `HistogramEqualization.cpp` — 直方图均衡化完整实现

---

### 4. 线性滤波 (`LinearFilter.cpp`)

**语言:** C++ / OpenCV

**描述:**
实现**3×3盒滤波器（均值滤波器）**——最简单的线性滤波器。核使用相等的权重：

```
1/9  1/9  1/9
1/9  1/9  1/9
1/9  1/9  1/9
```

每个像素被替换为其3×3邻域的算术平均值。这能平滑图像并减少噪声，但也会导致模糊（细节丢失）。

**文件:**
- `LinearFilter.cpp` — 盒滤波器完整实现
